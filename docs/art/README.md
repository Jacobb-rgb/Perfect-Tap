# Art references

- `lobby_concept.webp`: the target look for the town lobby (from the game's owner).
  Style bible: [`docs/ART_DIRECTION.md`](../ART_DIRECTION.md); layout and work split:
  [`docs/plans/LOBBY_PLAN.md`](../plans/LOBBY_PLAN.md).
- `lobby_blockout_hero.jpg`: the lobby blockout (one labeled box per set piece in
  `LobbyLayout.luau`) from the concept's camera angle (shot `blockout_hero`).
- `kenney_*.jpg`: renders of models from Kenney's **Factory Kit 3.0** (CC0, www.kenney.nl), used as the
  style reference for machines, pipes, tanks, hoppers and conveyors. The game rebuilds these shapes
  from Roblox parts in its own colors (no mesh files are shipped). Credit: Kenney (optional under CC0).
