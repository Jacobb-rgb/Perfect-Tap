# Things to do by hand in Roblox Studio

Almost everything (map, models, lighting, UI) is generated by code, so this list is short.
Tick the boxes as you go.

## Once, before testing
- [ ] **Home → Game Settings → Security → Enable Studio Access to API Services** = ON
      (needed so saving works when you test in Studio; only possible after the place is published once).
- [ ] Check **Lighting → Technology = Future** (already set in `TerraForge.rbxl`).
- [ ] Check **Workspace → StreamingEnabled = true** (already set).

## Optional polish (the game works without these)
- [ ] **Sounds:** the game uses built-in Roblox sounds. For nicer ones, open the
      **Toolbox → Audio**, search e.g. "rock hit", "metal clang", "stone scrape",
      pick sounds uploaded by **Roblox** (free to use), copy the ID and paste it into
      `src/shared/Config/SoundConfig.luau`.
- [ ] **Pickaxe swing animation:** the default tool-slash animation is used. You can
      make your own with the Animation Editor and paste its ID into `ToolData`.
- [ ] **Map tweaks:** you may move things in `Workspace.Map`. If you do, select `Map`
      and add the attribute `KeepMap` (boolean, true) so the server never rebuilds it.
      Ore grows at the invisible `Map.NodeSpawns` markers: duplicate/move them to add spots.

More items (game passes, badges, icon) are added in `PUBLISHING.md`.
